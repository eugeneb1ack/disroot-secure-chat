# Deployment verification

The release candidate passed the browser and HTTP checks in [the transport report](../public/secure-chat/reports/release-checks.md), including three participants exchanging MLS messages through the real Tor network. The production hostname is [disroot.website](https://disroot.website/secure-chat).

The main-site switch is pending the final immutable build and candidate check. This document will record the actual release revision and post-deployment results after that switch; a healthy candidate alone is not a production deployment.
